FLASHDROP PRIVACY POLICY WEBSITE
=================================

Files:
- index.html
- styles.css
- script.js
- assets/flashdrop-logo.jpg

NETLIFY DEPLOY:
1. Extract this ZIP file.
2. Open https://app.netlify.com/drop
3. Drag the extracted folder (the folder containing index.html) onto the page.
4. Wait for deployment. Netlify will provide a public HTTPS URL.
5. Open that URL in a private/incognito browser window to confirm it is public.
6. Paste the page URL into Google Play Console > Privacy Policy URL.
7. Also add a Privacy Policy link inside the FlashDrop app.

IMPORTANT REVIEW BEFORE PUBLISHING:
This policy is drafted from the details supplied for the current FlashDrop release:
- no internet/server connection is used by the app;
- no ads or analytics SDKs are currently included;
- nearby transfers use Wi-Fi Direct;
- location permission is used for nearby-device discovery;
- the inspected Kotlin transfer code did not implement app-level TLS/end-to-end encryption.

Verify these statements against the exact APK/AAB you submit. If the app's permissions, SDKs, network behavior, storage behavior, or transfer implementation changes, update this policy and the Google Play Data Safety form. The policy does not replace the Data Safety declaration.

The Google Fonts import is optional. The page remains usable with system fonts if Google Fonts cannot load. The site itself does not need Google Fonts to serve the policy text.
